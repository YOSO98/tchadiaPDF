Mots de passe

Il sera demandé pour ouvrir le PDF. Conservez-le précieusement : il ne peut pas être récupéré si vous l'oubliez. Laissez-le vide pour seulement restreindre l'impression et la modification (ouverture libre).
Distinct du mot de passe d'ouverture, il permet de modifier plus tard les droits ci-dessous. S'il est vide, le mot de passe d'ouverture est réutilisé : il devient alors obligatoire dès que vous restreignez un droit, sinon toute personne qui ouvre le PDF aurait tous les droits.

      Ce que protège vraiment un mot de passe PDF

      Le mot de passe d'ouverture chiffre réellement le contenu (AES-256, norme PDF 2.0) : sans lui, le fichier est illisible.

      Les droits (impression, copie, modification) sont respectés par les lecteurs honnêtes comme Acrobat, Aperçu ou les navigateurs, mais ils ne constituent pas une protection cryptographique absolue : une personne déterminée qui connaît le mot de passe d'ouverture, ou qui ouvre un PDF à ouverture libre, peut les contourner avec des outils spécialisés. C'est exactement la même limite que dans Acrobat Pro.

      Si le moteur AES-256 ne peut pas être chargé, un chiffrement de secours RC4 128 bits (norme PDF 1.4, lu par tous les lecteurs) est appliqué avec les mêmes mots de passe et les mêmes droits ; l'outil vous en informe alors clairement.
