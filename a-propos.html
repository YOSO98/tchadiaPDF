À propos de tchadiaPdf

tchadiaPdf est une boîte à outils PDF gratuite et illimitée : fusionner, diviser, faire pivoter, convertir vos documents en quelques clics, sans jamais les envoyer sur un serveur.

Qui fait tchadiaPdf

tchadiaPdf est développé par une seule personne, sur son temps libre, plutôt que par une entreprise. Le projet est ouvert : le code source est public sur GitHub, sous licence MIT, et chacun peut le lire, le vérifier, signaler un bug ou proposer une amélioration. Les informations légales formelles (éditeur, hébergeur) sont sur la page Mentions légales.

Pourquoi ce projet existe

La plupart des outils PDF gratuits en ligne fonctionnent en envoyant votre fichier sur un serveur distant pour le traiter, ce qui pose un vrai problème pour des documents souvent sensibles (pièces d'identité, contrats, dossiers administratifs, bulletins de salaire). tchadiaPdf part du principe inverse : si le traitement peut se faire entièrement dans le navigateur, il n'y a aucune raison de faire transiter le fichier ailleurs. C'est un choix technique assumé dès le départ, pas un argument marketing ajouté après coup : voir la page Pourquoi nous faire confiance pour la preuve concrète.

Vos fichiers restent chez vous

Contrairement à la plupart des services en ligne, tchadiaPdf traite vos documents directement dans votre navigateur. Vos fichiers ne sont jamais envoyés sur un serveur : personne d'autre que vous n'y a accès.

Comment le projet est financé

tchadiaPdf reste gratuit et sans compte grâce à deux sources de revenus, clairement séparées de vos fichiers :

  • De la publicité optionnelle (Google AdSense), affichée uniquement si vous donnez votre consentement via le bandeau du bas de page. Vous pouvez refuser sans perdre l'accès à aucun outil.
  • Des dons volontaires, via Ko-fi ou GitHub Sponsors, pour qui souhaite soutenir le projet directement (voir la page Soutenir le projet).

Aucun de ces deux modes de financement ne repose sur vos fichiers ou sur des données à leur sujet : la publicité fonctionne comme sur n'importe quel site, sans rapport avec le contenu que vous traitez.
