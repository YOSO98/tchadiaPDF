Pourquoi tchadiaPdf est gratuit

« Si c'est gratuit, c'est vous le produit » : la méfiance est légitime, surtout quand on confie un bulletin de salaire ou une pièce d'identité à un site web. Cette page explique, sans détour, comment tchadiaPdf peut être gratuit, sans compte et sans limite d'usage, et ce que vous donnez (ou pas) en échange.

1. Un site statique coûte presque rien à faire tourner

La plupart des services PDF en ligne envoient votre fichier sur leurs serveurs, le traitent, puis vous renvoient le résultat. Chaque conversion leur coûte de la puissance de calcul, de la bande passante et du stockage : il faut bien que quelqu'un paie, d'où les comptes, les quotas « 2 fichiers par jour » et les abonnements.

tchadiaPdf fait l'inverse : le traitement s'exécute dans votre navigateur, sur votre appareil, grâce à des bibliothèques JavaScript et WebAssembly (pdf-lib, pdf.js, qpdf, Tesseract). Le site lui-même n'est qu'un ensemble de fichiers HTML, CSS et JavaScript servis par un hébergeur statique (Cloudflare Pages). Il n'y a aucun serveur applicatif, aucune base de données, aucun stockage de fichiers. Les coûts fixes se résument au nom de domaine et au temps de développement. C'est ce choix d'architecture, et pas une générosité particulière, qui rend la gratuité tenable.

2. Le code est open source (licence MIT)

L'intégralité du code est publiée sur GitHub sous licence MIT. Concrètement : n'importe qui peut lire le code, vérifier qu'il fait ce qu'il annonce, le corriger, le réutiliser ou l'héberger ailleurs. Le projet est développé par une seule personne sur son temps libre, avec les contributions bienvenues de la communauté (voir à propos).

Cette ouverture est aussi une garantie pour vous : le dépôt contient un test automatisé qui vérifie, à chaque modification, qu'aucun fichier ne quitte le navigateur. Une promesse de confidentialité écrite dans des conditions d'utilisation peut changer ; un test public qui échoue si la promesse est rompue, c'est plus difficile à contourner discrètement.

3. Des dons volontaires

Les personnes qui le souhaitent peuvent soutenir le projet via Ko-fi (don ponctuel) ou GitHub Sponsors (soutien régulier). Ces dons couvrent des frais concrets (nom de domaine, outils de développement) et donnent du temps au projet. Aucun montant n'est attendu, aucune fonction n'est réservée aux donateurs, et le site reste identique pour tout le monde : détails sur la page Soutenir le projet.

4. De la publicité, seulement si vous l'acceptez

Le site peut afficher des publicités Google AdSense. Elles ne sont chargées qu'après votre consentement explicite dans le bandeau en bas de page. Si vous refusez, aucun script publicitaire n'est chargé, aucun cookie n'est déposé, aucune requête n'est envoyée à Google, et vous gardez l'accès à tous les outils. Votre choix est mémorisé dans votre navigateur uniquement, et modifiable à tout moment via le lien « Gérer les publicités ».

Deux précisions honnêtes. D'abord, les scripts publicitaires, quand vous les acceptez, fonctionnent comme sur n'importe quel site : ils transmettent des données techniques à la régie (voir la politique de confidentialité). Ils n'ont en revanche jamais accès à vos fichiers, qui ne transitent par aucun script tiers. Ensuite, une publicité affichée n'est pas une recommandation de notre part : nous ne choisissons pas les annonceurs.

Ce que « gratuit » veut dire ici, et ce que ça ne veut pas dire

  • Pas de compte, pas d'inscription : le site n'a ni base d'utilisateurs ni système d'authentification.
  • Pas de quota : aucune limite de fichiers par jour ou par mois. La seule limite est par lot (20 à 50 fichiers à la fois selon l'outil), pour que votre navigateur reste réactif, et vous pouvez enchaîner les lots autant que nécessaire.
  • Pas de « premium » : il n'existe pas de version payante avec plus de fonctions. Ce qui est sur le site est tout ce qui existe.
  • Pas de revente de données : il n'y a rien à revendre, les fichiers ne nous parviennent jamais. La mesure d'audience, si elle est activée, est anonyme et sans cookie (Plausible).
  • Gratuit ne veut pas dire parfait : certaines fonctions sont moins avancées que celles d'un logiciel professionnel payant (OCR moins précis, compression sans ré-échantillonnage, conversions Office en image paginée). Ces limites sont documentées sur chaque page d'outil et dans le comparatif avec Adobe Acrobat, plutôt que cachées.
  • Gratuit ne veut pas dire sans contrepartie pour l'auteur : le projet demande du temps. Les dons et la publicité consentie sont les deux moyens de le rémunérer en partie, sans jamais toucher à vos fichiers.

Questions fréquentes

Y a-t-il une version payante ou des fonctions bloquées ?

Non. Tous les outils sont disponibles en entier, sans compte, sans essai, sans quota journalier. Les seules limites sont techniques : 20 à 50 fichiers par lot selon l'outil, pour que le navigateur reste réactif, et la mémoire de votre appareil pour les très gros fichiers.

Mes fichiers servent-ils à financer le site ?

Non. Les fichiers ne quittent jamais votre navigateur, il est donc impossible de les analyser, de les stocker ou de les revendre. La publicité, si vous l'acceptez, fonctionne comme sur n'importe quel site web, sans rapport avec le contenu que vous traitez.

Que se passe-t-il si je refuse la publicité ?

Rien ne change : tous les outils restent accessibles. Aucun cookie publicitaire n'est déposé et aucune requête n'est envoyée à Google. Vous pouvez changer d'avis à tout moment via le lien « Gérer les publicités » en bas de page.

Le site peut-il devenir payant un jour ?

Le code est publié sous licence MIT : même si le site changeait de modèle, n'importe qui pourrait continuer à héberger les outils tels qu'ils sont aujourd'hui, gratuitement. C'est la garantie la plus solide qu'un projet puisse donner.
