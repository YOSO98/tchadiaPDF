Fidélité de conversion

Le PDF est généré en capturant le rendu visuel de votre page HTML, page par page au format A4 : le texte du PDF obtenu n'est donc pas sélectionnable ni cherchable. Par sécurité, les scripts éventuellement présents dans le fichier HTML importé ne sont jamais exécutés : seul le contenu visuel (texte, images, mise en forme CSS) est capturé.

  • Les ressources externes (polices, images distantes) ne sont chargées que si votre HTML les référence par une URL accessible publiquement ; les fichiers locaux référencés par un chemin relatif ne seront pas trouvés.
  • Chaque élément de premier niveau reste entier sur une même page, sans coupure au milieu.

Questions fréquentes

Comment convertir un fichier HTML en PDF gratuitement ?

Collez votre code HTML dans la zone de texte ou importez un fichier .html, puis cliquez sur « Convertir en PDF ». Le document est généré directement dans votre navigateur, sans envoi sur un serveur.

Puis-je convertir directement l'URL d'un site web ?

Non, cet outil ne récupère pas une page distante. Enregistrez d'abord la page depuis votre navigateur (Ctrl+S) puis importez le fichier .html obtenu.

Les scripts de ma page HTML sont-ils exécutés ?

Non, jamais. Par mesure de sécurité, le fichier est affiché dans un cadre isolé sans exécution de script : seul le rendu visuel (texte, images, styles CSS) est capturé pour construire le PDF.

Puis-je convertir plusieurs fichiers HTML en une seule fois ?

Oui, jusqu'à 20 fichiers à la fois. Chaque fichier .html devient un PDF distinct et l'ensemble est regroupé dans une archive ZIP à télécharger.
