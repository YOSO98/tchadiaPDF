Questions fréquentes

Comment extraire toutes les images d'un PDF ?

Déposez le PDF : l'outil détecte automatiquement chaque image embarquée dans le document et les regroupe pour un téléchargement en une seule fois.

Dans quel format les images sont-elles exportées ?

Chaque image est extraite dans son format d'origine quand c'est possible, puis l'ensemble est regroupé dans une archive ZIP à télécharger.

Et si mon PDF est un simple scan (une photo par page) ?

Un PDF issu d'un scan classique contient en général une seule grande image par page : l'outil l'extrait comme n'importe quelle autre image, une par page.

Mon fichier est-il envoyé sur un serveur ?

Non, la détection et l'extraction des images se font entièrement dans votre navigateur.
