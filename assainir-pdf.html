    Ce que cet outil ne fait pas

    Il retire ce qui est caché dans la structure du fichier, pas ce qui est visible sur la page.

    • Le texte et les images visibles ne sont pas caviardés. Pour masquer et supprimer réellement un passage sensible, utilisez Caviarder PDF.
    • La détection du texte masqué (texte en mode de rendu invisible) est heuristique et non exhaustive : du texte blanc sur fond blanc, couvert par une image ou hors de la zone recadrée n'est pas identifié. Vérifiez visuellement les pages signalées.
    • Le contenu situé hors de la zone recadrée est signalé mais pas supprimé.
    • Les champs de formulaire sont figés dans la page : leur valeur reste visible, seule la structure modifiable disparaît.
    • Les balises d'accessibilité (structure logique) et les index de recherche incorporés ne sont pas conservés dans le document reconstruit.

    Questions fréquentes

    Quelles informations masquées un PDF peut-il contenir ?

    Le nom de l'auteur et le logiciel utilisé (métadonnées), l'historique d'édition (XMP), des commentaires et notes de révision, des fichiers joints, des scripts JavaScript, des calques invisibles, des données propres à l'application d'origine, ou encore du contenu hors de la zone recadrée. Tout cela reste dans le fichier même si rien n'apparaît à l'écran.

    Comment être sûr que les éléments retirés ont vraiment disparu ?

    L'outil ne se contente pas de délier les objets : il reconstruit un document neuf dans lequel seuls les éléments conservés sont recopiés, puis relit les octets du fichier produit pour vérifier qu'aucun marqueur des catégories retirées ne subsiste. Le rapport affiché l'indique.

    Pourquoi les signets et les liens ne sont-ils pas cochés par défaut ?

    Ils ne contiennent en général aucune information sensible et servent à la navigation dans le document. Vous pouvez les cocher si vous souhaitez un fichier totalement épuré. Les éventuels scripts qu'ils portent sont retirés dans tous les cas si la catégorie JavaScript est cochée.

    Est-ce la même chose que caviarder un PDF ?

    Non. Assainir retire les données cachées dans la structure du fichier ; caviarder supprime un contenu visible sur la page (un nom, un montant). Pour un document vraiment propre, enchaînez les deux : caviardez d'abord, puis assainissez.

    Mon fichier est-il envoyé sur un serveur ?

    Non, l'analyse et l'assainissement se font entièrement dans votre navigateur. Le fichier ne quitte jamais votre appareil.
